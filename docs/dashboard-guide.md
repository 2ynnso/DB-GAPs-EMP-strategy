## 테이블 열

| 열 | 설명 |
|----|------|
| **판정** | 모멘텀 점수 기반 투자 행동 제안. 매수/확대·보유유지·관찰·매도/축소 4단계 |
| **티커** | ETF 코드 (예: A069500) |
| **ETF** | ETF 이름 |
| **분류** | 대회 자산 분류. 국내주식_지수 / 국내주식_섹터 / 해외주식_지수 / 해외주식_섹터 |
| **클러스터** | 전략 그룹. AI & Semiconductors / Core Equity Beta / Korea Cyclical Alpha 등 |
| **1M** | 최근 1개월 수익률 (약 21거래일) |
| **3M** | 최근 3개월 수익률 (약 63거래일) — 점수 산정의 핵심 기준 |
| **6M** | 최근 6개월 수익률 (약 126거래일) — 중기 추세 확인용 |
| **20D** | 현재 가격이 20일 이동평균선 위(Y) / 아래(N) — 단기 추세 |
| **60D** | 현재 가격이 60일 이동평균선 위(Y) / 아래(N) — 중기 추세 |
| **60D 고점 대비** | 최근 60일 고점 대비 현재 가격 낙폭. 0.00%이면 현재가 = 고점 |
| **상대순위** | 전체 주식 ETF 중 3M 수익률 기준 순위 (예: 1/130) |
| **점수** | 0–100 모멘텀 종합 점수. 절대 점수 70% + 상대순위 30% 가중 합산 |

---

## 점수 산정 방식

절대 점수(70점 만점) + 상대 순위 점수(30점 만점) 합산

**절대 점수 항목**

| 항목 | 조건 | 점수 |
|------|------|------|
| 1M 수익률 | 양수 | +20 |
| 3M 수익률 | 양수 | +20 |
| 6M 수익률 | 양수 | +15 |
| 20D 이동평균 상회 | Y | +15 |
| 60D 이동평균 상회 | Y | +15 |
| 60D 고점 대비 낙폭 | –3% 이내 | +15 |
| | –3% ~ –8% | +8 |
| | –8% 초과 | +0 |

**상대 순위 점수**: 전체 ETF 중 3M 수익률 백분위 × 30%
